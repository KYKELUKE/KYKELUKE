# ⭐ Proyectos destacados

## 🤖 VIVNA — Asistente de Nutrición con IA

Proyecto de chatbot basado en **RAG (Retrieval-Augmented Generation)** para consultar información a partir de documentos especializados.

**Tecnologías:**

`Python` · `Streamlit` · `LangChain` · `FAISS` · `Gemini` · `RAG`

---

## 💊 Ekuifarm — Sistema para Farmacia

Sistema orientado a la gestión de operaciones de una farmacia, con módulos para clientes, proveedores, empleados, productos, ventas y facturación.

**Tecnologías:**

`PHP` · `JavaScript` · `SQL Server` · `HTML` · `CSS`

---

## 📊 SISDE — Sistema de Autoevaluación de Desempeño

Aplicación de escritorio para registrar y generar información relacionada con procesos de autoevaluación de desempeño.

**Tecnologías:**

`C#` · `.NET` · `Windows Forms` · `QuestPDF`

---

## 🏨 EasyHotel — Directorio de Alojamientos

Proyecto orientado a facilitar la consulta de establecimientos de alojamiento en Perú mediante una plataforma digital.

**Tecnologías:**

`JavaScript` · `HTML` · `CSS` · `APIs` · `Bases de datos`
